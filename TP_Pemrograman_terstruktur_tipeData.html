1. Apersepsi: Menghubungkan Scratch ke Java

Konsep dasarnya sama persis, hanya beda cara penulisan!

Scratch (Blok Visual)

Logika di Scratch

Membuka Variabel:
buat variabel namaSiswa
Input Data:
tanya Masukkan Nama Anda dan tunggu
Output Teks:
katakan gabungkan [Halo ] (jawaban) selama 2 detik
Java (Pemrograman Teks)

Kode Java Setara

Deklarasi + Tipe Data Wajib: String namaSiswa;
Menggunakan Scanner: System.out.print("Masukkan Nama Anda: ");
namaSiswa = input.nextLine();
System.out.println & Konkat (+): System.out.println("Halo " + namaSiswa);

Perbedaan Utama yang Harus Diingat:

Di Scratch, variabel akan menyesuaikan angka/teks secara otomatis. Namun di Java, komputer membutuhkan kepastian jenis data sebelum membuat wadah memori (Tipe Data Terikat) dan setiap kalimat perintah wajib diakhiri dengan titik koma (;).

2. Concept 1: Variabel & Aturan Penamaan

Variabel adalah nama tempat penyimpanan sementara di memori RAM komputer.

Aturan Penamaan Java

  • Case-Sensitive: nama tidak sama dengan Nama.
  • Diawali huruf, _, atau $. Tidak boleh diawali angka!
  • Gunakan gaya camelCase (contoh: umurSiswa, totalHargaBarang).
  • Tidak boleh menggunakan kata kunci kata bawaan Java (misal: int, class, public).
💡 Anatomi: TipeData namaVariabel = nilaiAwal;

3. Concept 2: Tipe Data Java

Eksplorasi kategori tipe data primitif dan tipe data referensi (String).

Bilangan Bulat

byte, short, int, long

Untuk menyimpan angka tanpa desimal. Yang paling sering dipakai adalah int.

int umur = 16;
long populasi = 8000000000L;
Angka Desimal

float & double

Menyimpan angka berkoma/desimal. Standar utama adalah double.

double nilai = 88.5;
float ipk = 3.75f;
Karakter & Logika

char & boolean

char untuk 1 karakter ('A'), boolean bernilai true/false.

char grade = 'A';
boolean isLulus = true;
Referensi Teks

String

Tipe data non-primitif (Class) untuk deretan kata/kalimat. Dibungkus petik dua (" ").

String nama = "Budi Santoso";

4. Concept 3: Input dan Output (I/O)

Mengambil perintah dari pengguna via keyboard & menampilkan hasil ke konsol.

Menampilkan Output

Java memiliki dua metode pencetakan standar ke layar konsol:

System.out.println()

Mencetak teks lalu berpindah ke **garis baru** (newline).

System.out.print()

Mencetak teks **tanpa** berpindah garis (cursor tetap di samping).

Menerima Input (`Scanner`)

Gunakan class Scanner dari library java.util:

import java.util.Scanner;

Scanner input = new Scanner(System.in);
Method Scanner Tipe Data Target
nextLine()String (1 Baris penuh)
nextInt()int (Bilangan Bulat)
nextDouble()double (Desimal)
nextBoolean()boolean (true/false)
